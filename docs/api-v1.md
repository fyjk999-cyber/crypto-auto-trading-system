# API v1

Frozen control-plane contract: GET /health,/ready,/runtime,/account,/margin,
/positions,/orders,/trades,/ledger,/market,/regime,/signals,/strategies,/risk,
/reviews,/stress-tests,/performance,/daily-reviews,/learning,/memory,
/exchange-health. Control POST endpoints are authenticated, authorized, audited.
WebSocket envelope: event_type, event_version, timestamp, payload.
